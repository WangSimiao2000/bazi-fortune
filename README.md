# 称骨算命系统

纯前端实现的称骨算命 Web 应用，基于袁天罡称骨术，自动转换阳历到农历并计算节气月份。

## 功能特性

- ✅ 纯前端实现，无需后端服务器
- ✅ 双输入模式：阳历自动转换 / 手动输入节气月+农历日
- ✅ 支持男女性别选择，不同解命诗
- ✅ 精确农历转换（1900-2100年，正确处理跨年）
- ✅ 精确节气时刻计算（精确到小时）
- ✅ 完整的称骨诗数据库（2.1-7.2两，男女各52条）
- ✅ 详细的计算过程展示
- ✅ 响应式设计，适配手机/平板/桌面
- ✅ 风水玄学风格UI（深色背景+金色主题+楷体）
- ✅ 宽屏双栏布局（输入+结果并排显示）

## 使用说明

### 阳历模式（自动转换）
1. 选择性别（男/女）
2. 输入阳历出生年月日
3. 选择出生时辰（两小时为一个时辰）
4. 点击"测算命理"按钮
5. 查看详细计算过程和结果

### 手动模式（节气月+农历日）
1. 切换到"手动模式"
2. 选择性别
3. 输入出生年份
4. 选择节气月（正月到腊月）
5. 选择农历日（初一到三十）
6. 选择时辰
7. 点击"测算命理"查看结果

### 特殊说明

- **23点规则**：23:00-23:59算作次日子时
- **节气月**：系统自动根据节气计算月份（如立春后才算正月）
- **农历日**：系统自动将阳历转换为农历日期
- **跨年处理**：正确处理阳历年初对应上一年农历（如2001年1月→2000年农历）

## 算法说明

### 称骨四柱
- **年**：出生年份（用于查年骨重）
- **月**：节气月（以节气为界，非农历月）
- **日**：农历日（阳历自动转换）
- **时**：时辰（23点算次日子时）

### 计算流程
1. 输入阳历日期时间
2. 处理23点特殊情况（算次日子时）
3. 计算节气月（精确到小时）
4. 转换农历日期（含农历年）
5. 查询年/月/日/时骨重
6. 累加总骨重
7. 根据性别和骨重查询解命诗

## 示例

**输入**：男，阳历2000年11月7日凌晨0点

**计算过程**：
- 阳历转农历：2000年11月7日 → 农历2000年十月十二
- 节气转换：2000年11月7日0点 → 九月（立冬在7日18点，0点未到）
- 年份骨重：2000年 = 1.2两
- 月份骨重：九月 = 1.8两
- 日期骨重：农历十二日 = 1.7两
- 时辰骨重：子时 = 1.6两
- **总计：6.3两**

**结果**：命主为官福禄长，得来富贵定非常，名题金塔传金榜，定中高科天下扬。
