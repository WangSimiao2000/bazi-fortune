# 称骨算命系统

纯前端实现的称骨算命 Web 应用，基于生辰八字计算骨重并给出解命诗。

## 功能特性

- ✅ 纯前端实现，无需后端服务器
- ✅ 支持男女性别选择
- ✅ 输入阳历生日，自动转换农历日期
- ✅ 精确节气时刻计算
- ✅ 完整的称骨诗数据库（男女版本）
- ✅ 详细的计算过程展示
- ✅ 跨平台，任何浏览器都能使用

## 快速开始

### 方法一：直接打开（推荐）
双击 `index.html` 文件，在浏览器中打开即可使用。

### 方法二：使用本地服务器
```bash
# Python 3
python3 -m http.server 8000

# 然后访问 http://localhost:8000
```

## 使用说明

1. 选择性别（男/女）
2. 输入阳历出生年月日
3. 选择出生时间（精确到小时）
4. 点击"开始算命"按钮
5. 查看详细计算过程和结果

### 特殊说明

- **23点规则**：23:00-23:59算作次日子时
- **节气月**：系统自动根据节气计算月份
- **农历日**：系统自动将阳历转换为农历日期

## 技术实现

- **前端**: HTML5 + CSS3 + JavaScript
- **算法**: 
  - 完整的农历转换算法（1900-2100年）
  - 节气计算
  - 称骨重量计算
- **数据**: 完整的男女称骨诗数据库

## 示例

**输入**：阳历2000年11月6日晚上23点45分，男

**计算过程**：
- 阳历转农历：2000年11月6日晚上23点45分→ 算做农历次日 → 农历十月十二
- 节气转换：2000年11月6日晚上23点45分 → 九月
- 年份骨重：2000年 = 1.2两
- 月份骨重：九月 = 1.8两
- 日期骨重：农历十二日 = 1.7两
- 时辰骨重：子时 = 1.6两
- **总计：6.3两**

**结果**：命主为官福禄长，得来富贵定非常，名题金塔传金榜，定中高科天下扬。

## 注意事项

- 支持年份范围：1900-2100
- 输入的是阳历日期，系统自动转换
- 23:00-23:59算作次日子时
- 节气精确到日（简化算法）
